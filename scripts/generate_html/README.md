# 独立销量预测生成器

运行、输入输出路径及维护方式见项目根目录 README.md。

- 启动：`python main.py --no-open`。
- 页面仅包含本项目销量预测及其资源，模块注册只有 sales_forecast。
- 原始输入通过本项目根目录相对定位同级共享数据，保持只读。
- 销量汇总默认写入并读取 `../共享数据/订单汇总/鸿蒙智行销量数据汇总.xlsx`（相对于项目根目录），不回退本地旧汇总；这是唯一允许写入的共享派生文件，其他共享文件不可覆盖。
- HTML、网页资源、日志和缓存仍默认写本项目 `output_file/`。`main.py --output` 只指定 HTML 输出，不改变共享汇总位置；配套资源、日志和网页读取缓存随 HTML 输出目录保存；刷新缓存固定在本项目 `output_file/.cache/`，运行结束会同时清理两处缓存，不得写入共享目录。
- 刷新工具显式 `--output` 可指定自定义非共享汇总文件，仍不得覆盖原始输入或其他共享文件。`SHARED_DATA_ROOT` 的覆盖规则见项目根目录 README。
- 历史完整功能说明位于 ../../docs/原预测功能说明.md；旧订单分析耦合及发布说明已失效。
